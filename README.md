Welcome to AI-Architect

AI-Architect is a multi-agent system that supports software architecture design. It combines repository analysis, requirements clarification, architecture generation, literature-based evidence, and automated review in one workflow.

Getting Started

To start the application, simply run:

SETUP_AND_RUN.bat

The setup script automatically creates the required environment and installs the necessary libraries.

For the standard setup, you only need a Google Gemini API key. If you also want to use an additional model through KIConnect, you can provide a KIConnect API key as well.

After setup, the AI-Architect interface opens automatically.

You can then either:

explore two pre-generated Greenfield runs and two Brownfield runs, or
start a new run yourself by entering a system description and, optionally, an existing GitHub repository.
the saved run from the demonstration video is also included

Once a design is completed, AI-Architect runs an automated review and refinement process. After you accept the final design, the application generates a downloadable Markdown and PDF architecture report. Previous runs remain available in Run History, including the four comparison runs and the demonstration run.
